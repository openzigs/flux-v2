# [Feature] OAuth2/OIDC sign-in is closed to unknown users by default and limited to Google or generic OIDC

> Parent epic: **[Epic] Miniflux v2.3.3 (run 3) — Analysis of 2026-10-04 14:37:08 UTC**

## Description

(document) The operator manual states the sign-in contract explicitly, including who may be provisioned automatically.
- `OAUTH2_USER_CREATION` is described as "Set to 1 to authorize OAuth2 user creation"; when disabled (the default), "users must already exist in Miniflux or have a linked OAuth2 account to sign in".
- `OAUTH2_PROVIDER` accepts only the values "google" or "oidc".
- `OAUTH2_REDIRECT_URL` must be registered with the provider and is documented as something like `https://miniflux.example.org/oauth2/oidc/callback`.

(document) The operator-facing credential contract supports file-based secret injection, which is the documented mechanism for keeping secrets out of plain environment values.
- `METRICS_USERNAME_FILE` and `METRICS_PASSWORD_FILE` each point to a file containing the corresponding metrics-endpoint credential.
- `OAUTH2_CLIENT_ID_FILE` and `OAUTH2_CLIENT_SECRET_FILE` are documented as paths to a secret key exposed as a file containing the `OAUTH2_CLIENT_ID`/`OAUTH2_CLIENT_SECRET` value.

(code) OAUTH2_PROVIDER is declared as an empty-string default with a validator limiting accepted values to the choice set. Note the validator lists the choices as `{"oidc", "google"}`, which is the same accepted set as the requirement (order within the slice is irrelevant).
- `internal/config/options.go:469-476` sets `parsedStringValue: ""` and `validator: func(rawValue string) error { return validateChoices(rawValue, []string{"oidc", "google"}) }`.
- `internal/config/options.go:921-923` exposes `OAuth2Provider()`.

(code) The callback URL is a configurable option that is passed to the OAuth2 manager when constructing providers. The requirement's form constraint (a provider-registered callback such as https://miniflux.example.org/oauth2/oidc/callback) is an operational/documentation matter and is not enforced by any format validator in code.
- `internal/config/options.go:477-481` defines `OAUTH2_REDIRECT_URL` as a plain string defaulting to empty.
- `internal/config/options.go:925-927` exposes `OAuth2RedirectURL()`.
- `internal/ui/auth.go:55-63` passes `config.Opts.OAuth2RedirectURL()` into `oauth2.NewManager`.

(code) Both OAuth2 client credentials have file-backed options with `secretFileType` and a `targetKey`, so file contents populate the live credential options at parse time.
- `internal/config/options.go:441-446` defines `OAUTH2_CLIENT_ID_FILE` with `targetKey: "OAUTH2_CLIENT_ID"`.
- `internal/config/options.go:453-458` defines `OAUTH2_CLIENT_SECRET_FILE` with `targetKey: "OAUTH2_CLIENT_SECRET"`.
- `internal/config/parser.go:337-349` implements the shared `readSecretFileValue` reader used for secret files.
